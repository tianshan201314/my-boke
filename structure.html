文件职责

三、关键设计说明

  1. 数据模拟：文章、图书、菜单、友链、能力模块均以 JS 数组模拟，页面由 JavaScript 渲染；后续接入后端时只需替换数据源。
  2. 相对路径：所有本地资源引用均为相对路径，部署到 GitHub Pages 子路径下也能正常工作。
  3. 无外部依赖：图片与图标均为本地 SVG，页面离线可访问。
  4. 中文优先：中文为一级信息，英文仅用于系统编号、模块代号与状态标签。
  5. 安全：所有动态内容渲染前经过 HTML 转义，避免 XSS。
