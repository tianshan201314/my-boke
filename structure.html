一、目录树

二、文件职责说明

页面（根目录）

文件职责
index.html首页：吸顶导航、文章卡片网格、侧边栏、页脚、返回顶部按钮
article.html文章详情页：按 ?id= 渲染正文、上一篇 / 下一篇导航

structure.html项目结构页（当前页）：目录树、文件职责、设计说明

文件职责

js/main.js站点核心：POSTS 数据数组、页面渲染、分类筛选、代码复制、返回顶部

文件职责

文件职责

.gitignore忽略系统文件、编辑器配置、日志与临时文件
README.md仓库主页展示的项目说明

三、关键设计说明

  1. 数据模拟：文章全部存放在 js/main.js 的 POSTS 数组中，页面由 JavaScript 渲染；后续接入后端时只需替换数据源。
  2. 相对路径：所有本地资源引用均为相对路径，部署到 GitHub Pages 子路径下也能正常工作。
  3. 无外部依赖：图片与图标均为本地 SVG，页面离线可访问。
  4. 组件复用：首页与文章页共用侧边栏（个人信息、分类、最新文章），由 main.js 统一渲染。
  5. 安全：所有动态内容渲染前经过 HTML 转义，避免 XSS。
