# 项目结构说明

> 最后更新：2026-08-09

本文档记录 DevLog 个人技术博客的项目结构，说明每个目录和文件的用途。项目为纯前端实现（HTML + CSS + 原生 JavaScript），无框架、无构建步骤。

## 一、目录树

```text
my_boke/
├── index.html                  # 首页
├── article.html                # 文章详情页
├── about.html                  # 关于我
├── css/
│   └── style.css               # 全部样式
├── js/
│   └── main.js                 # 站点数据 + 渲染 + 交互逻辑
├── images/                     # 本地图片资源
│   ├── avatar.svg              # 博主头像
│   ├── favicon.svg             # 站点图标
│   ├── diagram-cache.svg       # HTTP 缓存流程图（文章配图）
│   └── covers/                 # 文章封面图
│       ├── cover-1.svg
│       ├── cover-2.svg
│       ├── cover-3.svg
│       ├── cover-4.svg
│       ├── cover-5.svg
│       └── cover-6.svg
├── docs/                       # 项目文档
│   ├── AI需求文档.md            # 需求整理与验收标准
│   ├── DEPLOY.md               # GitHub Pages 部署指南
│   └── 项目结构.md              # 本文档

├── .nojekyll                   # 跳过 Jekyll 构建（部署必需）
└── .github/
    └── workflows/
        └── deploy.yml          # GitHub Actions 部署工作流
```

## 二、文件职责说明

### 页面（根目录）

| 文件 | 职责 |
| --- | --- |
| `index.html` | 首页：吸顶导航、文章卡片网格（封面/标题/摘要/日期/分类/阅读时长）、侧边栏（个人信息、分类、最新文章）、页脚、返回顶部按钮 |
| `article.html` | 文章详情页：按 URL 参数 `?id=` 渲染标题/作者/日期/标签、正文内容块、上一篇/下一篇导航；文章不存在时显示友好提示 |
| `about.html` | 关于我：头像、自我介绍、技能标签、联系方式（邮箱/GitHub/掘金/Telegram） |

### 样式与脚本

| 文件 | 职责 |
| --- | --- |
| `css/style.css` | 全部样式：配色变量（GitHub 风格柔和蓝）、双栏布局、卡片网格、代码块、吸顶导航、响应式（920px 单栏、640px 收缩）、返回顶部按钮 |
| `js/main.js` | 站点核心逻辑：`POSTS` 文章数据数组、卡片/侧边栏/正文渲染、分类筛选、代码复制、返回顶部、滚动阴影 |

### 图片资源（`images/`）

| 文件 | 用途 |
| --- | --- |
| `avatar.svg` | 博主头像（侧边栏、文章页作者、关于页） |
| `favicon.svg` | 浏览器标签页图标 |
| `diagram-cache.svg` | 文章《HTTP 缓存》中的流程示意图 |
| `covers/cover-1 ~ 6.svg` | 六篇文章的封面图，与 `POSTS` 数组中的 `cover` 字段一一对应 |

### 文档（`docs/`）

| 文件 | 职责 |
| --- | --- |
| `AI需求文档.md` | 需求整理、设计规范、数据模型与验收标准 |
| `DEPLOY.md` | GitHub Pages 部署步骤与常见问题 |
| `项目结构.md` | 本文档 |

### 配置文件

| 文件 | 职责 |
| --- | --- |
| `.github/workflows/deploy.yml` | 推送 `main` 分支后自动部署到 GitHub Pages |
| `.nojekyll` | 空文件，让 GitHub Pages 跳过 Jekyll 处理 |
| `.gitignore` | 忽略系统文件、编辑器配置、日志与临时文件 |
| `README.md` | 仓库主页展示的项目说明 |

## 三、关键设计说明

1. **数据模拟**：文章全部存放在 `js/main.js` 的 `POSTS` 数组中，页面由 JavaScript 渲染；后续接入后端时只需将该数组替换为接口数据，渲染逻辑无需改动。
2. **相对路径**：所有本地资源引用均为相对路径，站点部署到 GitHub Pages 的子路径下也能正常工作。
3. **无外部依赖**：图片、图标均为本地 SVG，页面离线可访问；仅外链（GitHub、Codex 等）使用完整 URL。
4. **组件复用**：首页与文章详情页共用侧边栏（个人信息、分类、最新文章），由 `main.js` 统一渲染。
5. **安全**：所有动态内容渲染前经过 HTML 转义，避免 XSS。
