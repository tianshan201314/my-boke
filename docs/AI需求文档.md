# 个人技术博客网站 —— AI 需求文档

> 本文档用于指导 AI（或任何开发者）从零构建一个"个人技术博客"静态网站，也是本项目交付前的验收依据。

---

## 一、项目概述

构建一个**纯前端、无需框架**的个人技术博客网站，包含首页（文章列表 + 侧边栏）、文章详情页、关于我页三个页面。所有文章内容以 JavaScript 数组模拟，后续可平滑替换为后端接口数据。

目标用户：技术写作者本人及普通读者。
核心诉求：**内容可读、结构清晰、代码展示友好、手机与电脑体验一致**。

---

## 二、博客定位

本项目选择"个人技术博客"定位，其特征与其它类型对比如下：

| 博客类型 | 特点 | 本项目的取舍 |
| --- | --- | --- |
| **个人技术博客**（本项目） | 需要代码块展示、技术标签 | 保留：代码块 + 复制按钮、分类标签、阅读时长 |
| 生活记录博客 | 需要图片展示、时间线 | 不采用：时间线排布与博客定位不符 |
| 专业知识博客 | 需要结构化内容、阅读体验 | 部分采用：正文采用 1.7 行高的阅读排版 |
| 作品集博客 | 需要大图展示、简约风格 | 不采用：以文章列表为主，非大图画廊 |

## 三、核心页面需求

### 1. 首页 `index.html`

- 顶部导航栏
  - 左侧：网站名称 / Logo（`DevLog` + 图标）
  - 右侧：首页 | 文章 | 关于
  - 当前页面导航链接以下划线高亮（`.nav-link.active`）
  - 导航栏吸顶：页面滚动时始终固定在顶部，滚动后显示轻微阴影
- 主体内容区（双栏）
  - 左侧约 70%：文章列表
    - 每篇文章为独立卡片，桌面端以两列网格排列、间距均匀，移动端自动切换为单列
    - 卡片包含：封面图、标题、摘要（约 100~150 字）、发布日期、分类标签、阅读时长
    - 鼠标悬停时卡片微微上浮并加深阴影
    - 支持按分类筛选（分类名旁显示文章数量；点击后列表实时更新并高亮当前分类）
    - 文章详情页的分类同样可点击，会跳转到首页并自动应用对应筛选
  - 右侧约 30%：侧边栏
    - 个人信息卡片（头像、姓名、一句话介绍、GitHub / 邮箱 / 关于我）
    - 文章分类列表（含各分类文章数量）
    - 最新文章列表（前 5 篇，含缩略图与日期）
- 页脚：版权信息、建站时间、"由 Codex 驱动"小标识

### 2. 文章详情页 `article.html`

- 顶部：文章标题、作者名称、发布日期、分类标签、正文标签
- 正文内容区，支持以下内容块：
  - 二级标题（`h2`，左侧蓝色强调条）
  - 段落
  - 无序列表
  - 引用块
  - 代码块（深色主题，带语言标识和"复制"按钮）
  - 图片（带说明文字）
- 底部导航：上一篇 / 下一篇链接（按发布日期排序）
- 容错：文章 id 不存在时显示友好提示

### 3. 关于我 `about.html`

- 个人头像 / 照片
- 自我介绍（3 段）
- 技能标签列表
- 联系方式：邮箱、GitHub、掘金、Telegram

## 四、样式与设计规范

```yaml
整体风格: 简洁、专业、阅读舒适
配色方案:
  背景色: 白色 (#ffffff)
  主文字: 深灰色 (#333333)
  弱化文字: 灰 (#6b7280)
  强调色: 柔和蓝 (#0969da)（GitHub 风格链接蓝）
  导航栏背景: 浅灰蓝 (#f6f8fa)
  卡片背景: 浅灰 (#f9fafb)
  边框: 浅灰 (#d0d7de)
  代码块: 深色底 (#1f2937) + 浅色字 (#e5e7eb)

排版:
  正文字体: 系统默认字体栈（含 PingFang SC / Microsoft YaHei）
  标题字体: 加粗
  正文字号: 16px
  行间距: 1.7（阅读舒适区间 1.6-1.8）
  代码字号: 14px，等宽字体

适配:
  - 电脑端（> 920px）: 双栏布局，左侧 7 份 / 右侧 3 份，侧边栏吸顶
  - 移动端（<= 920px）: 单栏布局，侧边栏移动到底部
  - 小屏（<= 640px）: 收缩内边距、卡片与标题字号
```

交互细节：

- 卡片 hover 上浮 + 阴影加深，封面图轻微放大
- 导航 / 标签 hover 有强调色反馈
- 当前页导航链接显示蓝色下划线
- 代码块复制按钮点击后变为"已复制"
- 右下角圆形"返回顶部"按钮：滚动超过一屏才显示，点击平滑回到顶部
- 遵循 `prefers-reduced-motion`，关闭动画

## 五、技术方案

- **纯前端**：HTML + CSS + 原生 JavaScript，不使用任何框架或构建工具
- **数据模拟**：文章全部保存在 `js/main.js` 的 `POSTS` 数组中，页面通过 JS 渲染
- **无外部依赖**：所有图片均为本地 SVG（封面、头像、流程图），离线可访问
- **浏览器兼容**：现代 Chrome / Edge / Safari / Firefox

## 六、数据模型设计

### 文章对象（`POSTS` 数组元素）

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `id` | string | 文章唯一标识，用于详情页 URL | `'http-cache-guide'` |
| `title` | string | 标题 | `'深入浅出 HTTP 缓存'` |
| `summary` | string | 摘要（100~150 字） | `'HTTP 缓存是前端性能的基石……'` |
| `date` | string | 发布日期 `YYYY-MM-DD` | `'2026-07-15'` |
| `category` | string | 分类（来自 `CATEGORIES`） | `'前端开发'` |
| `tags` | string[] | 标签列表 | `['HTTP', '缓存']` |
| `cover` | string | 封面图路径 | `'images/covers/cover-5.svg'` |
| `readTime` | number | 预计阅读时长（分钟） | `6` |
| `content` | object[] | 正文内容块（见下表） | — |

### 正文内容块类型（`content` 数组）

| type | 字段 | 渲染结果 |
| --- | --- | --- |
| `h2` | `text` | 二级标题（带强调条） |
| `h3` | `text` | 三级标题 |
| `p` | `text` | 段落 |
| `list` | `items: string[]` | 无序列表 |
| `quote` | `text` | 引用块 |
| `code` | `lang` + `code` | 代码块（带复制按钮） |
| `img` | `src` + `alt` + `caption?` | 图片 + 可选图注 |

### 后续接入后端（接口契约建议）

当前 `POSTS` 为前端常量，替换为接口时建议保持相同结构：

```http
GET /api/posts              # 文章列表（含分页参数 page / pageSize）
GET /api/posts/:id          # 文章详情
GET /api/posts?category=xx  # 按分类筛选
```

渲染函数（`renderPostCard` / `renderBlocks`）无需改动，只需将数据源从常量改为 `fetch` 结果。

## 七、验收标准

### 页面完整性

- [ ] 首页导航含 Logo 与三个链接，当前页高亮正确
- [ ] 首页左侧展示全部文章卡片，卡片含封面、标题、摘要、日期、分类、时长
- [ ] 首页右侧侧边栏包含个人信息、分类列表（含数量）、最新文章
- [ ] 点击分类可筛选文章，再次点击"全部文章"恢复
- [ ] 点击卡片/标题可进入对应文章详情页
- [ ] 详情页顶部含标题、作者、日期、分类与标签
- [ ] 详情页正文支持标题、段落、列表、引用、代码块（可复制）、图片
- [ ] 详情页底部含上一篇 / 下一篇，且指向正确文章
- [ ] 关于页含头像、自我介绍、技能标签、联系方式
- [ ] 页脚显示版权信息

### 样式与适配

- [ ] 配色与规范一致（白底、深灰文字、蓝色强调、浅灰卡片）
- [ ] 行高 1.7，正文阅读舒适
- [ ] 桌面端为双栏布局（7:3），侧边栏吸顶
- [ ] 920px 以下切换单栏，侧边栏移至正文下方
- [ ] 640px 以下无横向溢出，导航与卡片自适应

### 代码与工程

- [ ] 不使用任何框架与构建工具，纯 HTML/CSS/JS 可直接打开运行
- [ ] 文章数据全部集中在 `POSTS` 数组，便于替换后端
- [ ] 无外部 CDN 依赖，离线可用
- [ ] 所有动态内容经过 HTML 转义，避免 XSS
